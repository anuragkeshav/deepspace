# Deep Space Archive

> An interactive visual archive of the universe — exploring distant objects through procedural particles, motion, and cinematic storytelling.

![Deep Space Archive](https://placehold.co/1600x900/090B0C/F5F5F2?text=Deep+Space+Archive)

## Overview

**Deep Space Archive** is an experimental interactive web experience built around the idea of exploring the universe through light, motion, and data.

Instead of presenting astronomical objects as static images, the project uses procedural visualizations and particle-based animations to create an immersive digital archive.

The experience moves through distant cosmic objects, observation methods, and the traces of light that allow us to reconstruct worlds far beyond our reach.

## Featured Objects

The archive explores a selection of extraordinary astronomical objects:

- **Sagittarius A\*** — The supermassive black hole at the centre of the Milky Way.
- **TON 618** — An extraordinarily distant and powerful quasar.
- **Pillars of Creation** — Vast structures of gas and dust inside the Eagle Nebula.
- **ʻOumuamua** — An interstellar object observed passing through our Solar System.
- **Kepler-452b** — A distant exoplanet orbiting a Sun-like star.

## Experience

### How We Look

The universe does not reveal itself all at once.

The experience follows four stages:

**Observe**  
We collect faint signals arriving from objects separated from us by unimaginable distances.

**Trace**  
Light, motion, and repeating patterns reveal the paths hidden inside the data.

**Decode**  
Multiple observations turn scattered signals into a physical picture.

**Understand**  
The object becomes part of the larger story of the universe.

## Visual System

The website uses a restrained scientific-archive aesthetic:

- Near-black astronomical environments
- Procedural particle systems
- Interactive galaxy visualization
- Dynamic astronomical objects
- Slow organic motion
- Pale blue and white highlights
- Editorial typography
- Scroll-driven transitions
- Responsive layouts

The visual language intentionally avoids traditional space-themed UI in favor of a quieter, editorial approach.

## Technology

Built with modern browser technologies:

- HTML5
- CSS3
- JavaScript
- Canvas API
- Procedural particle systems
- Responsive CSS
- Scroll-based animation

No external astronomical image assets are required for the primary visual experience.

## Design Direction

The interface is inspired by:

- Scientific archives
- Editorial publications
- Museum catalogues
- Astronomical observatories
- Minimalist digital experiences

The goal is to make the website feel less like a traditional astronomy website and more like a **digital archive from the future**.
